# Homebrew Tap for DS Menu Bar

Install DS Menu Bar:

```sh
brew install --cask jiiim/tap/ds-menu-bar
```

Upgrade it:

```sh
brew upgrade --cask ds-menu-bar
```

Uninstall it:

```sh
brew uninstall --cask ds-menu-bar
```

DS Menu Bar requires macOS 26 or later, Apple Silicon, a compatible
user-managed `ds4-server`, and a DwarfStar-compatible GGUF. See the
[DS Menu Bar repository](https://github.com/jiiim/ds-menu-bar) for setup,
supported models, release notes, and source code.
